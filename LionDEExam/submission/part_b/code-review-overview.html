結論

不可部署：11 個問題，其中 5 個 P0

主要問題是 TWD 訂單在換匯時被丟掉（#4）、dim_member 每次執行被覆寫成只剩有變更的會員（#6）、事實表以 append 寫入導致重跑重複（#9）。程式內建的驗證只印筆數，沒有斷言，上述問題在執行時都不會被發現。

P2#1

CSV 不指定 schema

load_sources 讀四個 CSV 時沒有給 schema，所有欄位都是字串，例如金額是 "13100.0"。後面的比較與運算都依賴隱式轉型。

影響結果取決於 ANSI 設定。ANSI 關閉（Fabric 的 Spark 3.x runtime）時，目前資料不受影響，但上游格式改變就會靜默丟單；ANSI 開啟（Spark 4 預設）時，三個增量檔的金額都帶小數點，管線直接失敗。

修法明確定義 schema 並設定 FAILFAST；enforceSchema 設為 false，表頭與 schema 不一致時報錯。
