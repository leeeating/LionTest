# 學習：把本專案的觀念內化成自己的能力

這裡是我從這份 take-home 挑出觀念、學到真的懂的紀錄。教材由 AI 依 `/teach` skill 產生：觀念取自本專案（事件、AI 錯誤、決策），正式解釋引用一手資源。這裡不是繳交物的結論。

| 檔案 | 內容 |
|---|---|
| `MISSION.md` | 為什麼學、學會的樣子（我自己寫） |
| `CONCEPTS.md` | 從專案萃取的候選觀念與學習狀態 |
| `RESOURCES.md` | 一手資源清單 |
| `lessons/` | 課程，一課一個觀念，Markdown |
| `records/` | 學習紀錄，只有在對話中證明真的懂了才寫 |

**開始**：在 repo 根目錄啟動 Claude Code，輸入 `/teach`（或 `/teach <觀念>`）。第一次會先列出候選觀念讓我挑、請我寫 mission；之後每次接續進度。規則見 `.claude/skills/teach/SKILL.md`。
