使用者 2026-10-10 說明兩種文件：
1. **理解問題時的紀錄**（筆記）：「先讓人針對一件事情迅速了解，再慢慢讓人了解目前遇到的問題，以及建議的解決方式。好的文件系統不會把所有內容放在同一個檔案中。」
2. **提交的報告**：「完整的有結構的文件，類似小論文。」

**Why:** 我把理解過程的觀察（dataset 筆記、增量檔性質）和繳交報告混著寫，筆記全塞同一檔，報告又像條列清單。

**How to apply:** 筆記分三層：入口檔（30 秒懂是什麼）→ 問題清單（一行一項附連結）→ 細節檔（一份只講一件事）。繳交報告則是單一檔、論文式結構（摘要、背景、方法、發現、建議、結論），引用筆記當證據來源。具體位置與切法問使用者。與 [[feedback-keep-it-simple]] 一起權衡，不要切得過碎。
